# 盘前竞价选股框架 — 待确认问题清单（供外部 agent 完善）

> 背景：0109 regime×打法回测显示 19 个交易日全部落在 cold/cold_to_warming。本文先做数据完整性审计，再定位根因，最后列出需另一个 agent 确认/补全的具体问题。

## 一、数据完整性审计

- `projects/duanxianxia/captures` 从 **2026-05-19** 起，约 **26 个交易日**快照。
- 0109 可用 **19 天**（6 天缺竞价快照 regen 失败；其余缺日线或 <20 行被剔）。
- 平行的 M3 回补 flat CSV 约 21 天 / 5910 行，量级相同。
- **结论：不是漏看数据，而是整段实盘捕获窗口（5 月中～7 月初，约 7 周）可用数据就这么多，且恰好是一段持续弱势行情。**

## 二、根因：regime 轴失真

0109 分层用的情绪周期 label 来自遗留模块 `duanxianxia_v7_1_regime.compute_regime`，判定逻辑：

- `cold_to_warming` = 昨 QX≤30 且 今 QX≥35
- `hot` = 今 QX≥**65** 或 LBBX≥5（单一高门槛）
- `cold` = 今 QX≤30 **或** DT≥20 **或** KQXY≥10 **或** 广度≤0.28（四选一宽网）
- 否则 `normal`

**结构性偏置**：cold 是四条件 OR（极易触发），hot 是 QX≥65 单高门槛（几乎打不到，本窗口 QX 中位数 ~29），normal/warming 只剩 QX 31-64 且其他三项都不触发的窄缝。→ 弱市里几乎每天都被压成 cold。

**另一层问题**：项目里新算了 12 因子连续分 `market_env_score`（0-100，含连板高度/涨停家数/昨表现等），但**没有接进 regime 标签**。之前看到的“冷市 vs 热市超额差 ~7x”很可能是用这个连续分中位数切分得到的，与离散 label 不是同一套定义。

## 三、待确认问题清单

### L0 周期定义层（最优先，当前失真）
1. 你的周期判定用**绝对阈值**还是**滚动分位数**？跨多长历史？**样本里有没有主升/高潮/退潮周期？**
2. hot 门槛该不该相对化（QX≥65 在弱市永远触发不了）？
3. cold 的四选一 OR 宽网该不该改成加权计分？
4. 连续 `market_env_score` 该不该直接替代离散 regime 做分层轴？

### 收益口径层
5. 现在只算**当日** `excess=(close-open)/preclose`，对隔日/多日打法（连板接力、龙头）严重低估。是否需补 T+1、T+2 多口径？
6. 首板打板若按打板成交，买入价应是涨停价而非开盘价；打板类更该看**打中封板率 + 次日溢价**。

### 打法/样本池层
7. 板块/连板标签稀疏（ztpool 行常缺连板层级标签）→ S1/S3 池过宽、S2/S4 池过薄（S4 冷市仅 12 样本/暖市 1）。**连板层级、是否首板、是否龙头**的权威字典你那边怎么定？
8. 打法内排序现用竞价成交额；0055 验证里“竞价成交额+换手率+跳空”复合(ICIR 0.926)更优。你实测最优排序因子是什么？

### 因子有效性层（已验证，供对齐）
9. **正**：竞价成交额(Top3 超额 11.2)、竞价换手率、跳空、复合 comp_SD、主力净流入(~0.10)。**负/噪声**：封单额 915/920、grab_strength、涨停池晋级因子(-0.07)、v9 现金流涨跌幅(0049 数据泄漏)。
10. 你反复强调的**题材集中度 / 主线契合度（我们尚未建的 L1/L2 层）**具体怎么量化？用什么数据源？

### 市场覆盖层（最根本缺口）
11. 你是否有**更长历史（含 2024/2025 热市、高潮、退潮周期）**的竞价+日线数据可共享？否则 S2/S4/龙头打法与热市路由在本地永远无法证伪。

### 最想要的三个答案
- ① 周期判定：相对分位 or 绝对阈值？跨多长？有没有热市样本？
- ② 你实测最有效的盘前竞价选股因子/组合（带 IC 或胜率证据）？

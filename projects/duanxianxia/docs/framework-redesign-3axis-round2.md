# 盘前框架三轴重构 — Round 2（peer 反馈 × 本地口径对齐）

> peer（Wudao 侧）核心结论：最大问题不是参数微调，而是**周期轴/收益轴/主线轴三层混在一起**；且 Wudao 当前不足以支撑 2024/2025 长周期竞价回测（只适合 2026 截面 + 字段定义核实 + 题材层量化设计）。
> 关键前提：两边**数据口径不同**，不能互传数据也不能字面“统一口径”，只能对齐**思路**。

## ✅ 已定案（不再讨论）
- **bidStrength 分母 = FF（自由流通市值）**。bidStrength = 竞价成交额 / FF。本地竞价表市值本就是 FF，无全表 FLOAT 也不需要。不再提 FLOAT。

## 1. 直接采纳（思路层，与口径无关）

- **三轴分离**：环境轴（周期）/ 收益轴 / 主线轴，不再混为一个打分。
- **环境轴**：离散 regime → 连续 `market_env_score` 为主轴，离散 cold/neutral/hot 只做展示标签。（我侧已有 12 因子 market_env_score，半成品）
- **门槛相对化**：hot=score≥P70/P75、cold=score≤P25/P30、中间为过渡带；不再用绝对阈值（QX≥65 在弱市永不触发，等于把热市打法硬禁用，污染回测）。
- **cold 入池**：四选一 OR 宽网 → 逐条计分 + 最小总分 + 按分排序。
- **收益轴**：只看当日 → 并行 R0/R1/R2；且按打法拆（hot_open/trend 看 R0；weak_to_strong/leader 看 R1/R2）。
- **首板打板买入价**：开盘价 → 涨停价(+滑点)；拆成 “命中率（封/成/炸） + 收益率（次日溢价/R1/R2）”。
- **排序**：单一竞价成交额 → 复合标准化排序（与本地 0055 comp_SD 结论一致）；分池排序而非全池一套。
- **主线轴**：consistency ≠ 主线契合度；需二次构造 theme_concentration(L1) + theme_fit(L2)。
- **龙头**：不能写成单字段，必须复合建模（板位+主线强度+主线内核心度+竞价强度+承接）。

## 3. 改造顺序（按我侧 ~20 天/全冷现实调整 peer 的 P0）

peer 的 P0 里“环境轴相对化”在我侧有硬约束：**qxlive 环境历史只有 ~19–26 交易日且全冷，40–60 日滚动分位根本凑不齐。** 所以：

- **P0a（不依赖长历史，先做）**：收益轴 R0/R1/R2 + 打法拆分收益；复合排序（bidStrength(FF) + 换手 + 量比 + 跳空）。这两项马上能落、不受全冷污染。
- **P0b（半成品，可先接线）**：regime 标签改由 market_env_score **排序/分位**派生（替掉 v7.1 绝对阈值）；但分位基底暂用**扩张窗口(min 15 日)+样本内分位**，标注“未达稳态”，等历史补齐再换 40–60/120 日。
- **P1（主线轴）**：用 kaipan.plate.summary 构造 theme_concentration（涨停数/资金 HHI）+ theme_fit（个股 concept → top-K 主线），**标明是涨停/资金口径而非高开一致性口径**。
- **P2（历史库）**：在本地历史竞价快照补齐前，不对 S2/S4/龙头打法下最终统计学结论（peer 也无法提供可信 2024/2025 竞价库）。

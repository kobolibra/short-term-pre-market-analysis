## 数据结论（仅冷市 / 微回暖成立）

1. **S1 首板打板 = 冷市唯一显著正 EV 打法**：Top3 超额 +9.39%、Top5 +4.66%，且**跌停率 0%**。胜率仅 0.40 → 典型右偏（少数大肉覆盖多数小亏），必须**分散 + 严格止损**，不能重仓单票。竞价成交额排序是有效的强度筛。
2. **S2 低位连板接力 = 冷市明确负 EV**：Top3 -2.83%、胜率 0.19。冷市里做连板接力就是接盘。→ **冷市禁 S2**。
3. **S3 低吸反弹 = 状态依赖**：冷市 flat（-0.06%，胜率 0.46），但**微回暖时转强**（Top5 +3.49%、胜率 0.87、跌停 0）。→ S3 是**回暖信号确认后**才开的打法。
4. **S4 高标龙头 = 样本不足**（冷 12 / 暖 1），无统计意义；且逻辑上本应在主升 / 高潮才有效，而这段没有热市。→ **维持冷市禁 S4，待热市样本**。
5. **baseline v9 BUY 冷市跌停率高达 27%**（每 4 个 BUY 有 1 个吃跌停），而 S1 同期跌停率 0% 且超额更高。→ **冷市用「竞价成交额排序的首板」比当前 v9 BUY 逻辑更稳更肉**，可反哺 v9 冷市 gate。
